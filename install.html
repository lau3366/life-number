生命數字

加到主畫面，像 App 一樣打開，離線也能用

你已經是從主畫面打開的，安裝完成了。
你現在是在 聊天 App 裡面打開這個網頁，這裡沒辦法加到主畫面。
請點右上角「⋯」，選 在 Safari 中打開；或者複製連結，貼到瀏覽器打開。
開啟生命數字

先點上面的按鈕打開，再照下面的步驟加到主畫面。

  1. 1用 Safari 打開，點「分享」

    在 Safari 打開生命數字，點螢幕下方的分享按鈕（方框加向上箭頭）。
    看不到的話，先點右下角的 「⋯」 再點「分享」。

  2. 2選「加入主畫面」

    在彈出的選單往下滑，找到 「加入主畫面」。

    拷貝 ⧉
    加入書籤 □
    加入個人收藏 ☆
    加入主畫面

  3. 3點右上角「新增」

    名字已經填好「生命數字」，直接點 「新增」。

    取消加入主畫面新增
    生命數字lau3366.github.io

  4. 4完成

    主畫面會出現「生命數字」圖示，以後直接點它打開就可以，沒有網絡也能用。

    相機
    相片
    訊息
    生命數字

  1. 1用 Chrome 打開，點「⋮」

    在 Chrome 打開生命數字，點右上角的 「⋮」。

    lau3366.github.io/life-number

  2. 2選「加到主畫面」

    在選單中點 「加到主畫面」（有些手機寫「安裝應用程式」）。

    新分頁
    書籤
    分享…
    加到主畫面

  3. 3點「安裝」或「新增」

    確認名稱後點 「安裝」。

    安裝應用程式
    生命數字
    取消安裝

  4. 4完成

    主畫面或應用程式清單裡會出現「生命數字」。

    電話
    相機
    Chrome
    生命數字
